API Reference¶

Core API¶

Stable v4 package facade.

Phase 3 establishes declarations and value models only. Operational cryptography is intentionally unavailable.

class cryptography_suite.Policy(policy_id: str, profile: str = 'custom')¶

Bases: object

An identified policy value without an evaluator.

The caller may carry an already assigned nonsecret policy identifier. Canonical policy serialization, identifier derivation, composition, and authorization are deferred.
